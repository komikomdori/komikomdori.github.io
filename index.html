KOMDORI Report Drive

KOMDORI Report Drive is a personal-use automation integration that stores and verifies personal reporting files in an account authorized through Google OAuth.

What the integration does

  • Stores generated personal report images and application-managed backup files in the authorized Google Drive account.
  • Reads file metadata and checks uploaded content to verify that storage operations completed correctly.
  • Supports a private scheduled workflow using exercise, nutrition and recovery records from separately authorized sources.

Who can use it?

This integration is configured for its operator's personal use. It is not a public health service, diagnostic tool, or application offered for general registration.

Data access and privacy

Google Drive access is requested only through an explicit Google OAuth authorization. Public information on this website does not give visitors access to Google Drive reports, account data, OAuth credentials, or private automation repositories.

See the Privacy Policy for details about the types of data processed, their use, storage, and deletion.
